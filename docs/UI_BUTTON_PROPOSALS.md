# UI Button Proposals

Date: 2026-04-20
These are practical button ideas for the map UI and timeline workflow.

## Top priority

1. Compare Sites
- Action: Select 2-3 sites and open side-by-side metrics.
- Value: Fast decision support for location and capacity planning.

2. Export Filtered CSV
- Action: Export only currently filtered datacenters.
- Value: Easy handoff to finance, PM, and ops teams.

3. Focus Region
- Action: Quick region chips (Nordics, EU, US, APAC).
- Value: Faster navigation and cleaner map exploration.

4. Capacity View Toggle
- Action: Switch marker mode between count, gW, and pW overlays.
- Value: Better visibility into actual power footprint.

## Secondary ideas

5. Timeline Density Toggle
- Action: Group events by month/quarter/year.
- Value: Reduces clutter in high-event periods.

6. Site Status Quick Filter
- Action: One-click filters for planned, construction, online.
- Value: Cleaner triage workflow.

7. Copy Share Link
- Action: Copy URL containing current filters and selected site.
- Value: Easy sharing in Slack and issue comments.

8. Reset View
- Action: Restore default map zoom, filters, and timeline state.
- Value: Fast recovery from deep exploration.

## Suggested placement

- Toolbar right side: Export Filtered CSV, Copy Share Link, Reset View.
- Toolbar left side: Region chips and status filters.
- Sidebar footer: Compare Sites action after multi-select.
- Timeline header: Timeline Density toggle.
